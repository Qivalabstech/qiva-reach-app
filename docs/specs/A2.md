# A2 · Email and Google sign-up

**Status:** Approved by Razam Sir 13 Oct 2026. Email part built; Google part waiting for the Google OAuth client.

Build notes: the return page is `/auth/callback` (accepts both same-browser link and any-browser link). Google button and PostHog events are added when the Google client and PostHog account exist.

## User story
As a new visitor, I can create an account with my email (magic link) or my Google account, so I can start without a password. Later I can connect LinkedIn to the same account.

## Acceptance criteria (locked)
Email magic link and Google login both work; the account can connect LinkedIn later.

## Screens
1. **/sign-in** (single screen, 390 px friendly)
   - Heading: "Sign in to Qiva Reach"
   - Button "Continue with Google" (white, Ink border)
   - Divider "or"
   - Email field + button "Email me a sign-in link" (the one Marigold action)
   - After send: "Check your inbox. We sent a link to name@example.com. It works for 1 hour."
   - Errors: "That email address doesn't look right. Check it and try again."
2. **/auth/callback** handles the link/Google return, then redirects: new user → /onboarding, returning user → /app.
3. **/app** placeholder home (signed-in only) with the user's name and a "Sign out" button.

## Data
- Supabase Auth creates the user. Database trigger `handle_new_user` creates profile, personal workspace, owner membership, free subscription and empty voice profile (already in migration 1).
- No passwords stored by us. Minimum personal data: email, name and photo if Google provides them.

## Behaviour rules
- Signed-out users visiting /app or /onboarding go to /sign-in.
- Magic-link emails are sent by Supabase for now; moved to Resend branded template with N1 in Phase 2.
- PostHog event: `signed_up` (method: email|google) and `signed_in`.
- Rate limit: Supabase default (email send limit); clear message if hit.

## Acceptance tests (Playwright)
1. Enter valid email → "Check your inbox" shown; invalid email → error message.
2. Opening a valid magic link lands on /onboarding for a new user and on /app for a returning user.
3. Google button starts the Google flow (checked against Supabase test config; full flow tested manually once).
4. Signed-out visit to /app redirects to /sign-in.
5. New user has exactly one workspace, one owner membership and a free subscription (database check).
6. Page works at 390 px; keyboard focus ring visible; reduced motion respected.

## Needs from founders
Supabase project, Google OAuth client, Resend later. LinkedIn is not needed here.
