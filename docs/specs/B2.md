# B2 · Tone presets

**Status:** Draft, waiting for approval (Razam Sir + Arman Hussain)

## User story
As a user, I pick a style for my posts (for example story-led or data-driven) on top of my own voice, and I can compare all five on the same topic before choosing.

## Acceptance criteria (locked)
5 presets (Professional, Story-led, Contrarian, Hinglish-friendly, Data-driven) give visibly different output in a side-by-side test.

## What a preset does
A preset changes the shape of a post: how it opens, how it is built, sentence length and what it leans on. The voice profile (B1) still decides wording, emoji use, signature phrases and banned phrases, so a preset never makes the user sound like someone else. Banned phrases apply to every preset.

| Preset | Shape of the post | Example opening (illustration only) |
|---|---|---|
| Professional | Clear point, short reasons, calm and practical close | "Three changes that improved how we onboard clients." |
| Story-led | A real moment first, then the lesson; first person, past tense | "Last year a client almost left. One call changed that." |
| Contrarian | Challenges a common belief in line one, then argues it fairly | "Posting every day is bad advice. Here is what works." |
| Hinglish-friendly | Natural Hindi and English mix in Roman script, plain and conversational; technical terms stay in English | "Client ne kaha price kam karo. Maine yeh kiya." |
| Data-driven | Leads with a number or finding the user supplies, then what it means | "We tested hooks for six weeks. Three patterns kept winning." |

Rule for Data-driven: the model may use only numbers the user typed in the topic or notes. It never invents statistics; with no number given it writes a how-to-measure angle instead.

## Screens
1. **/app/voice** gets a "Tone preset" section: 5 cards plus "No preset, just my voice" (the default). One selected at a time; saved with "Save voice profile" from B1.
2. **/app/voice/presets** "Compare presets"
   - Field "What is the post about?" prefilled with a suggestion from the user's niche; user can edit; optional "Facts or numbers to use".
   - Button "Show all five" (the one Marigold action). Five short samples (about 90 words) appear side by side on desktop and stacked on a 390 px phone, each labelled with its preset.
   - Each card has "Use this preset" (Ink button) which saves it and returns to /app/voice.
   - A card that fails shows "This one didn't load. Try again." with a retry; the others stay.
3. Per-draft override of the preset comes with the post writer (C2), not here.

## Data
- `voice_profiles.preset` already exists (`professional`, `story_led`, `contrarian`, `hinglish_friendly`, `data_driven`, or null).
- Preset instructions live in `src/ai/prompts/presets.v1.ts`, one block per preset, under version control.
- Comparisons use `ANTHROPIC_MODEL_FAST`, run in parallel, are not saved, and are logged in `ai_usage` (feature `preset_preview`).
- Limit: 10 comparisons a day per user, with a clear message.

## Compliance
Text the user types plus their saved voice profile go to the AI model. Same privacy note as B1. Nothing touches LinkedIn.

## Behaviour rules
- All five samples return within 15 seconds.
- Banned-phrase check runs on every sample; a sample that fails it is regenerated once.
- PostHog events: `presets_compared`, `preset_selected` (preset name only).

## Acceptance tests ("visibly different")
1. Automated, with stored sample outputs for one fixed topic: no two presets have more than 50% word overlap; Hinglish contains at least 3 common Hindi words in Roman script; Data-driven contains only numbers from the input; Story-led opens in the past tense in the first person; Contrarian's first line disagrees with a common belief (checked by a small rule list, then reviewed by a person).
2. Blind test with Arman and 2 other people: 10 shuffled samples without labels; each person matches at least 4 of 5 presets correctly.
3. A banned phrase typed into the profile never appears in any sample.
4. Playwright: compare, choose a preset, reload, selection persists; failed card retries without clearing the others.
5. RLS: another user cannot read or change the preset.
6. 390 px phone, keyboard only, visible focus; samples are readable by a screen reader in order.
